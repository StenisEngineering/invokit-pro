# InvoKitPro v14 — Roadmap & Upcoming Features Update

This update adds visible product-roadmap and coming-soon features while keeping InvoKitPro offline-first.

## Added

- Product Roadmap page in the sidebar
- Cloud Protect & Roadmap section inside Settings
- Visible upcoming features:
  - Quote Builder with install-rate quotation table
  - Cloud Protect Backup
  - Multi-device sync
  - Payment links
  - Client portal
  - Team access
  - Expense tracking
  - Email invoice to client
  - Approval workflow
  - Advanced business reports
- Clear offline-first / cloud-ready messaging
- Backup button on the roadmap page
- Service worker cache version update

## Important

Cloud Protect, payment links, client portal, team access and sync are displayed as planned features only. They are not enabled until secure backend accounts, storage rules, authentication and payment integrations are implemented.
