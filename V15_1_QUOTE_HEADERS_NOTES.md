# InvoKitPro v15.1 — Quote Headers & Sub-Headers Update

This update improves the v15 Quote Builder before live deployment.

## Added
- Quote/invoice section headers inside the line item table.
- Quote/invoice sub-headers or section notes inside the line item table.
- Preview/print support for both headers and sub-headers.
- Mobile alignment for quote section rows.
- Service worker cache bump: invokit-v15-1-quote-headers.

## Why this matters
Quotes can now be grouped professionally, for example:
- A. Materials
- Supply only items
- B. Installation / Labour
- Optional extras

This makes quotations clearer for construction, installation, repairs, printing, catering, and project-based work.
